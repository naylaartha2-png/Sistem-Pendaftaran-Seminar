      Sesudah / FIX

      function daftarFix(nama) {
  nama = nama.trim();
  if (peserta.length >= KUOTA)
    return gagal("Kuota seminar sudah penuh.");
  if (!nama)
    return gagal("Nama tidak boleh kosong.");
  if (!/^\p{L}[\p{L} .'-]+$/u.test(nama))
    return gagal("Nama tidak valid (tanpa angka).");
  if (peserta.some(p => p.toLowerCase() === nama.toLowerCase()))
    return gagal("Nama sudah terdaftar.");
  peserta.push(nama);
  return { ok: true, pesan: "Berhasil" };
}

      BugPenyebabDampakPerbaikan
      1. Nama tidak validIsian nama tidak divalidasi.Nama kosong, hanya spasi, atau mengandung angka/simbol (misalnya "sit1") tetap terdaftar dan menghabiskan kuota.Cek nama tidak kosong dan hanya berisi huruf dengan regex.
      2. Nama gandaTidak ada pemeriksaan nama yang sudah terdaftar.Satu orang bisa mendaftar berkali-kali dan memakan banyak kursi.Cek dengan some() (tidak peduli huruf besar/kecil).
      3. KuotaJumlah peserta tidak dibandingkan dengan kuota.Peserta ke-6 dan seterusnya tetap diterima, melebihi kapasitas.Cek peserta.length >= KUOTA.

      Hasil pengujian setelah fix: ketiga kasus ditolak dengan pesan yang sesuai dan jumlah peserta tidak bertambah. Versi BUG menerima ketiganya sehingga data menjadi tidak valid.
